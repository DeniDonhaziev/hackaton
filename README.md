# КРОНА

Ознакомительный сайт по кейсу ДПиООС: автоматическое проектирование озеленения города с учётом подземных коммуникаций.

## Запуск локально

Откройте `index.html` в браузере или:

```bash
npx serve .
```

## Содержание

- проблема и контекст озеленения Москвы
- пайплайн DXF → ограничения → план → DXF
- возможности сервиса, нормативная база, аудитория
